# V1-M1 — Process creation và isolation

## Mục tiêu

Chạy sensor service và vehicle middleware dưới dạng hai Linux process riêng,
được một launcher tạo và theo dõi.

## Luồng control

```text
v1_process_launcher
        │
        ├── fork() → child → exec() → sensor_service
        │
        └── fork() → child → exec() → vehicle_middleware
                                      │
                                      └── waitpid()
```

## Core cần học

- `fork()` tạo bản sao process tại thời điểm gọi.
- Sau `fork()`, parent và child có PID và address space riêng.
- `exec()` thay executable image của child; PID thường được giữ nguyên.
- `_exit()` dùng trong child khi `exec()` thất bại để child không chạy tiếp
  logic của parent.
- `waitpid()` giúp parent thu exit status và tránh zombie process.
- `WIFEXITED`, `WEXITSTATUS`, `WIFSIGNALED` dùng để phân tích kết quả child.

## Thread/multithread so với process

Thread trong một process chia sẻ heap và global memory. Process mới không tự
chia sẻ các vùng memory đó. Vì vậy sensor service và vehicle middleware hiện
chỉ log dữ liệu local; chưa có telemetry flow giữa chúng.

M1 cố ý chưa dùng IPC. Nếu thêm IPC ngay, sẽ khó phân biệt lỗi process
lifecycle với lỗi communication. IPC sẽ là nội dung của V1-M2.

## Vì sao chọn launcher đơn giản

Launcher dùng native Linux APIs để làm rõ process lifecycle. `systemd` sẽ phù
hợp hơn cho deployment thực tế, nhưng được để sau khi hiểu `fork`, `exec`,
`waitpid` và exit status.

## Verification

```sh
`cmake --build build
ctest --test-dir build --output-on-failure
./build/v1_process_launcher \
  ./build/sensor_service \
  ./build/vehicle_middleware`
```

Quan sát PID của launcher và hai child. Thử truyền path sai để quan sát `exec`
failure và exit code 127. Dùng `ps` hoặc `strace -f` nếu có sẵn.

## Interview checkpoint

Trước V1-M2, cần giải thích được:

- process khác thread thế nào;
- `fork()` và `exec()` khác nhau ra sao;
- vì sao child không được tiếp tục chạy parent logic khi `exec()` lỗi;
- zombie process là gì;
- parent thu exit status bằng cách nào;
- vì sao process isolation dẫn tới nhu cầu IPC.
